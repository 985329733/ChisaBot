# ADR-0012：目前只做单用户，去掉朋友账号与邀请

- 状态：已采纳
- 日期：2026-10-15
- 相关：取代 [ADR-0011](0011-gateway-accounts.md)（签名身份部分保留）、DESIGN.md §65、BACKLOG CB-040

## 背景

ADR-0011 在登录网关里做了朋友账号（邀请链接、重置、停用）和签名身份，#128 上线。上线后生产的「设置 → 管理 → 账号」页读不到账号列表；
用户 2026-10-15 09:11 决定「目前不做多人」。生产上除了内置管理员没有任何朋友账号（只有一条 e2e 用过的邀请，对应账号已删）。

## 决定

- 去掉：应用的「账号」设置页与 `lib/accounts`；网关的 `/auth/admin/*`（列表 / 邀请 / 停用 / 重置 / 删除 / 直接创建）、`/auth/invite`、
  登录页的邀请 / 重置表单；网关只认 `config.json` 的管理员（账号名不分大小写），以前朋友账号留下的会话启动时清掉，非管理员名下的手机换不到会话。
- 保留：网关给管理员会话签名身份（`identitySecret` / `CHISABOT_GATEWAY_SECRET`）、nginx 转发 `X-ChisaBot-Identity`、应用里按人隔离的代码
  （`server/src/auth/gateway-identity.ts` 及各路由的 owner 过滤）——删它们风险大于收益，而且单用户下行为和以前一样。
- 不删数据表：网关 SQLite 的 `accounts`、`invites` 表和 `sessions.user_id` 列原样留着（两周观察期规则同样适用）。

## 后果

- 想分享给朋友时，只能共用管理员账号（等于给出全部数据和设备），所以现在不分享。
- 重新打开的条件：用户明确要多人；先确定额度（CB-045）和管理入口为什么在生产读不到，再从 git 历史（#128）取回界面与接口，重新过一遍隔离 e2e。
