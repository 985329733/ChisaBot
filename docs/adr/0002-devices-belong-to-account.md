# ADR-0002：设备属于账号，不属于某个机器人

- 状态：已采纳
- 日期：2026-10-12
- 相关：DESIGN.md §16、§45；docs/pc-node.md；表 `devices`

## 背景

PC 节点最初按机器人授权（`device_bot_access`）。用户（2026-10-12）：「需要有一个设备列表，列出所有已经关联的设备。关联的设备
可以被任何一个 bot 进行管理」。

## 决定

- 设备挂在用户账号下；用户的每个机器人都拿到在线设备的 `device_*` 工具（设备 id / 名字 / 主机名都可指定，只有一台在线时可省略）。
- 别人的团队 Bot 拿不到。`device_bot_access` 保留但不再读取（瘦身 P5 再删）。
- 能力权限（关闭 / 询问 / 允许）、允许的文件夹、审计、急停都是**按设备**设置，与机器人无关。新设备默认「询问」（§45）。

## 后果

- 换机器人不用重新授权设备。
- 想让某个机器人碰不到电脑，目前只能靠能力权限整体控制；如以后需要按机器人限制，作为新 ADR。
