这台电脑

离线
■ 紧急停止中：这台电脑拒绝一切远程操作。

能力

默认全部关闭。「询问」= 每次弹窗确认；「允许」= 直接执行。修改会同步到网页和手机。

允许的文件夹

文件类能力只能访问这些文件夹（含子文件夹）。

也可以在网页 设置 → 设备 里添加。

哪些机器人可以使用这台电脑，在网页的设备详情里设置。

本机操作记录

这台电脑执行过的远程操作（完整记录在网页设备详情的「操作记录」里）。

通用

开机自动启动
登录 Windows 后在托盘里静默运行并自动连接。
高风险操作始终在本机确认
命令行、写入文件、鼠标键盘即使设为「允许」，也在这台电脑上弹窗确认。
设备名称
在网页和机器人工具里显示。
