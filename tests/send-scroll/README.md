# 5 分钟内连续发消息不翻页（DESIGN.md §94）

`sendscroll.mjs` —— 只在预览里跑（会向假模型发消息、建一个「临时测试（会删除）」机器人）。

- 预览的默认模型指到 `tests/bot-state/mock-model.mjs`（SLOW / WORK / 普通一句）。
- `BASE=http://127.0.0.1:<预览端口> WIDTHS=1280,390 OUT=/out node tests/send-scroll/sendscroll.mjs`
- 页面里的 `Date` 换成可加偏移的版本（`localStorage["cbsend-off"]`），用来模拟「过了 6 分钟」；刷新后那一步把
  `GET …/sent-at` 的回复改成「6 分钟前」（服务器时刻按服务器自己的「现在」换算，本机拨表骗不了它）。
- 每帧采样每一行离视口顶边的位置、离底部距离、滚动容器 spacer、我们的留白、输入框高度。

检查：
- c2 / c3 / c5 / r7（上一条 <5 分钟，含刷新后靠服务器时刻）：0 次往回挪；上移不超过下面长出来的高度（+ 输入框长高）；
  滚动容器 spacer 不变大（不新留一屏空白）；新消息没被翻到顶上；最后在底部。
- a4 / r8（>5 分钟，含刷新后）：新消息对齐到顶上（离顶 < 140px）、留出空白、0 次往回挪。
- type：输入框里打 7 行字，对话只为钉住底部往上挪（总上移 = 输入框长高），0 次往回挪，仍在底部。
