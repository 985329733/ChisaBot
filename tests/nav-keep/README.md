# 切回机器人页不刷新（DESIGN.md §98，CB-084）

`nav.mjs` 在**预览**（生产库副本、免登录管理员、假模型）里打开一段长对话，往上滚一点，然后在 1280 亮 / 390 手机下走：

- 设置 →「返回聊天」、待处理 → 左栏点机器人、设置 → 电脑与设备 → 浏览器后退、设置 → 浏览器后退；
- 每次回来逐帧（requestAnimationFrame）判定：0 次文档加载、0 帧空白 / 骨架、首帧和最后一帧的滚动位置与离开前一致、回来后 0 次跳动、0 次读整段消息。

可选：

- `STREAM=1`：一次性机器人（标题「临时测试（会删除）」，跑完删除）发 `SLOW`（假模型 40 句 × 260 ms），写到第 5 句时去设置，3 秒后回来——离开期间一直在写、回来第一帧就有对话、回来 2 秒内不重新接入 / 不读历史、写完 40 句不重复；再发一条，新消息和回答照常出现。
- `SWITCH=1`：左栏换到 `AGENT2`（默认 `general-assistant`）→ 换成那段对话、和上一段零重叠；去设置停 15 秒——藏着的聊天 / 右栏 0 次计算机控制权 / 标签 / 组件授权 / 面板 / 同步请求；回来是刚才那段；地址换回第一段——内容正确、无残留。

```sh
# 假模型（OpenAI 兼容，端口 4012），把预览的默认模型指向它
node tests/nav-keep/mock-model.mjs &
# 预览（dev 免登录）
BASE=http://127.0.0.1:<端口> AGENT=<有长对话的机器人 id> STREAM=1 SWITCH=1 node tests/nav-keep/nav.mjs
```

需要 `playwright-core` 和 Chromium（应用镜像里的 `/ms-playwright`）。截图写到 `/out`。`STREAM=1` 会创建 / 删除一次性机器人并发消息，**只在预览跑**；其余流程只导航、不写。
一个预览容器只跑一轮（docs/testing.md §5）。
